# Aurora Hotel — Assignment #3: Responsive Web Design

## Topic
Hotel Website

## Project Goal
Create a polished, multi-page, responsive hotel website using only HTML and CSS. The website adapts to mobile, tablet and desktop screens and demonstrates Flexbox, CSS Grid, native HTML interactions, accessible forms and responsive media.

## Target Audience
Tourists, business travellers, couples and families looking for city accommodation.

## Team and Page Ownership
- Meizamkhan — `index.html` (Home page)
- Dilnaz — `rooms.html` (Rooms & Suites)
- Ayazhan — `about.html` and `booking.html` (About, Booking & Contact)

> The current team has three members. Confirm instructor approval because the assignment document states four students per team.

## Main Pages
- `index.html` — introduction, benefits, featured rooms, guest experience
- `rooms.html` — six-item room catalogue, amenities and stay information
- `about.html` — hotel story, values, statistics, facilities and guest journey
- `booking.html` — static demonstration form, contact information and FAQ
- `demo-result.html` — utility result page for the static form; it does not replace a main page

## CSS Files
- `css/style.css` — mobile-first base styles
- `css/responsive.css` — min-width media queries for wider layouts

## Breakpoints
- Base: small/mobile layout
- `48rem` (about 768px): tablet layout, two-column grids, horizontal navigation
- `64rem` (about 1024px): desktop layout, three-column room catalogue
- `90rem` (about 1440px): wide desktop spacing adjustments

## Flexbox Evidence
1. Main navigation
2. Hero layout
3. Feature cards
4. CTA and form actions

## Grid Evidence
1. Six-item room catalogue
2. Amenities grid
3. Values grid
4. Statistics grid
5. Booking form field grid
6. FAQ grid

## Native HTML Interaction
The FAQ uses `<details>` and `<summary>` without JavaScript.

## Static Form Limitation
The booking form is a demonstration only. It uses native HTML validation and opens `demo-result.html`. No information is sent, stored or processed. A real booking system would require a backend or another server-side service.

## How to Open Locally
1. Extract the ZIP file.
2. Open `index.html` in a browser.
3. Use the navigation to move between pages.

## Testing Widths
Test at:
- 320px
- 375px
- 768px
- 1024px
- 1440px

Also test keyboard navigation, visible focus, 200% zoom and at least two browsers.
